# Company Economy — Playtest Guide v1

## 1. เปิดเกม

- **ลิงก์ playtest (GitHub Pages)**: เปิด URL ที่ได้รับจากผู้พัฒนา (รูปแบบ
  `https://<owner>.github.io/Company-economy/`) ได้ทั้งบนคอมพิวเตอร์และมือถือ Android —
  ไม่ต้อง login, ไม่ต้องติดตั้งอะไร
- **รันเองจาก repo**: `npm run serve` แล้วเปิด `http://localhost:8080/`
  (หรือ static server ใด ๆ ที่ serve โฟลเดอร์ repo — เกมเป็น static ล้วน)

หน้าแรกจะ redirect ไปที่ `ui/hotseat.html` (ตัวเกมเต็ม) อัตโนมัติ

## 2. โหมดแนะนำสำหรับครั้งแรก

ค่าเริ่มต้นบนหน้า Setup คือโหมดที่แนะนำอยู่แล้ว: **คุณ (Human) vs Bot 1 ตัว**
กด **Start Match** ได้เลย ไม่ต้องแก้อะไร
(อยากดูบอทตีกันเอง: เปลี่ยนทุก slot เป็น Bot แล้วนั่งดูได้)

## 3. เป้าหมายของเกม

ทำ **รายได้สะสมถึง $2,400 ก่อนใคร** (เมื่อมีคนถึง ทุกบริษัทได้เล่นรอบสุดท้ายอีก 1 รอบ
แล้วตัดสินผู้ชนะจากรายได้สะสม) — เพดาน 14 รอบ

## 4. ลูปของแต่ละรอบ

วางแผน → Submit → ดูตลาดขายของ ~20 วินาที → อ่านสรุปรอบ → รอบถัดไป

## 5–11. การเล่นในหน้า Planning (แท็บซ้ายมือ)

- **HQ (รอบแรกเท่านั้น)**: เลือกทำเลจากการ์ดหรือจิ้มป้ายบนแผนที่ — กลางเมืองแพงแต่ใกล้ร้าน
  ชานเมืองถูกแต่ไกล กด **Confirm HQ Location**
- **Product**: เลือกตำแหน่งสินค้า (Economy/Mainstream/Premium) และตั้งราคาในกรอบ
- **Hire**: จ้างพนักงาน — Sales เปิดการ pitch ร้าน, Marketing เปิดแคมเปญ, Logistics เพิ่มเที่ยวส่ง
  (จ้างรอบนี้ เริ่มใช้ slot ได้รอบหน้า)
- **Marketing**: ยิงแคมเปญรายย่าน — เพิ่ม awareness ไม่ใช่ยอดขายตรง ๆ ยิงซ้ำย่านเดิมได้ผลลดลง
- **Sales**: **Pitch This Store** เพื่อขอขึ้นชั้นวาง / **Assign Coverage** เพื่อรักษาความสัมพันธ์ร้าน
- **Logistics**: **Assign Shipment** ส่งสต็อกไปร้านที่มี (หรือกำลัง pitch) — ไม่มีของ = ไม่มียอดขาย
- **Submit**: ปุ่มล่างสุด → หน้า Review สรุปแผน → **Submit & Resolve** (ถ้ามีผู้เล่นคนถัดไป
  จะเป็นหน้า "ส่งเครื่องต่อ" แทน)

## 12. Selling Phase (~20 วินาที)

ดูคนเดินออกจากบ้าน/คอนโด/โรงแรมไปซื้อของที่ร้านจริง ๆ ตามผลเศรษฐกิจ รถส่งของวิ่งจาก HQ
ป้ายแคมเปญโผล่ตามย่าน — ปรับความเร็ว **x1/x2/x4** หรือ **Skip** ได้ (ไม่เปลี่ยนผลลัพธ์)

## 13. อ่าน Summary

การ์ดของแต่ละบริษัท: รายได้ / จำนวนที่ขาย / ส่วนแบ่งตลาด / ต้นทุนทุกบรรทัด
(COGS, เงินเดือน, ค่าเช่า, ขนส่ง, การตลาด, จ้าง-เทรน-ตั้งบริษัท) / กำไร / เงินสด
พร้อมคำแนะนำ เช่น "ของหมดชั้น — ส่งเพิ่ม"

## 14. Save / Resume

เกม save อัตโนมัติทุกจบรอบ (localStorage ในเบราว์เซอร์) — ปิดแท็บแล้วกลับมา
หน้าแรกจะมีปุ่ม **Resume** ให้เล่นต่อ / กด New Match เมื่อจบเพื่อล้าง save

## 15. สิ่งที่อยากให้ช่วยสังเกต

- เข้าใจไหมว่าแต่ละรอบกำไร/ขาดทุนเพราะอะไร (อ่านจาก Summary พอไหม)
- ตัดสินใจ HQ/ราคา/จ้างคน รู้สึกมี tradeoff จริงไหม
- Bot เล่นสมเหตุสมผลไหม รู้สึกแข่งขันไหม
- Selling Phase 20 วิ สนุก/นานไป/ข้อมูลพอไหม
- เงินตึงเกิน/หลวมเกินช่วงไหน
- UI ตรงไหนงง กดยาก หรือบังแผนที่ (โดยเฉพาะบนมือถือ)

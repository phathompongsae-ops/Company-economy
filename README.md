# God Brave

เกม 2D pixel fantasy แนวจัดทีม auto-battler ภาษาไทย สร้างกองกล้า 4 คนจาก 6 อาชีพแล้วพิชิตหอคอย 20 ชั้น มี Break Gauge, Brave Arts, Tactical Auto, อุปกรณ์, แต้มสกิล, พรชั่วคราว และบอสสุดท้ายแบบสุ่มจาก controlled pool

## เล่นในเครื่อง

ต้องใช้ Node.js 20 ขึ้นไป

```bash
npm run serve
```

เปิด `http://127.0.0.1:4173`

## ตรวจสอบ

```bash
npm test
npm run balance
```

เกมเป็น static site ใช้ Vanilla JavaScript, HTML, CSS และ Canvas 2D ไม่มี dependency ภายนอกและไม่มี asset เชิงพาณิชย์

รายละเอียดโครงสร้างอยู่ที่ `docs/ARCHITECTURE.md` และผลการทดสอบสมดุลอยู่ที่ `docs/BALANCE_REPORT.md`
